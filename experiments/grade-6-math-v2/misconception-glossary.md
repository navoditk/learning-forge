# Grade 6 Math v2 misconception glossary

Every `misconceptionCodes` entry in `skill-records-v2.json` is a slug
(`SkillSchema`'s `^[a-z0-9-]+$` pattern), which cannot carry a description
inline. This glossary documents the precise, observable learner error each
code names, so a reviewer or tutor-hint author never has to guess intent from
the slug alone. Codes were tightened during independent-review remediation so
each one names a specific, checkable behavior rather than a vague category.

| Skill                                        | Misconception code                                                           | Observable learner error                                                                                                                                                 |
| -------------------------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ratio-language-and-meaning                   | `reverses-ratio-order`                                                       | States a ratio in the opposite order from the one requested (e.g., gives boys-to-girls when girls-to-boys was asked).                                                    |
| ratio-language-and-meaning                   | `confuses-part-to-part-with-part-to-whole`                                   | Uses a part-to-whole quantity (e.g., girls to total students) where a part-to-part ratio was required, or vice versa.                                                    |
| rate-and-proportional-reasoning              | `divides-quantities-in-reversed-order-for-unit-rate`                         | Divides the base quantity by the measured quantity instead of measured-by-base, producing an inverted unit rate.                                                         |
| rate-and-proportional-reasoning              | `uses-addition-instead-of-multiplication-for-scaling`                        | Adds a constant amount to scale a ratio instead of multiplying by a scale factor.                                                                                        |
| rate-and-proportional-reasoning              | `treats-percent-value-as-whole-number-without-dividing-by-100`               | Uses a percent's numeral directly in a computation without converting it to a proportion or decimal.                                                                     |
| fraction-division                            | `inverts-wrong-factor`                                                       | Takes the reciprocal of the dividend instead of the divisor before multiplying.                                                                                          |
| fraction-division                            | `drops-units-from-quotient-answer`                                           | Reports a numeric quotient without the unit or context needed to interpret it (e.g., "3" instead of "3 batches").                                                        |
| multi-digit-number-operations                | `misaligns-decimal-point-when-adding-or-subtracting`                         | Lines up digits by place without aligning decimal points, producing an incorrect sum or difference.                                                                      |
| multi-digit-number-operations                | `drops-remainder-when-context-requires-it`                                   | Reports only the integer quotient and omits or ignores a remainder that the context requires interpreting.                                                               |
| factors-multiples-and-distributive-structure | `selects-lcm-value-when-asked-for-gcf`                                       | Reports the least common multiple when the greatest common factor was requested, or the reverse.                                                                         |
| factors-multiples-and-distributive-structure | `lists-a-multiple-as-a-factor`                                               | Includes a number's multiple (e.g., 24 as a factor of 12) in a factor list.                                                                                              |
| factors-multiples-and-distributive-structure | `factors-out-a-common-factor-that-is-not-the-greatest`                       | Factors a sum using a shared factor that is not the greatest common factor, leaving the two numbers inside the parentheses still sharing a common factor greater than 1. |
| rational-number-meaning                      | `assumes-negative-number-always-has-smaller-magnitude`                       | Assumes any negative number has smaller magnitude than any positive number, without comparing absolute values.                                                           |
| rational-number-meaning                      | `ignores-real-world-sign-meaning`                                            | Drops or ignores the real-world meaning of a number's sign (e.g., treats -20 feet as unrelated to "20 feet below").                                                      |
| rational-number-representation               | `plots-x-and-y-coordinates-in-reversed-order`                                | Plots the y-coordinate value along the x-axis and the x-coordinate value along the y-axis.                                                                               |
| rational-number-representation               | `compares-by-denominator-size-alone-ignoring-numerators-and-equivalence`     | Compares fractions by denominator size alone (e.g., assuming a larger denominator always means a larger fraction), ignoring numerators and equivalent-value reasoning.   |
| rational-number-operations                   | `applies-sign-rule-from-one-operation-to-a-different-operation`              | Applies a sign rule learned for one operation (e.g., multiplication) to a different operation (e.g., addition).                                                          |
| rational-number-operations                   | `adds-magnitudes-instead-of-finding-signed-difference`                       | Adds the magnitudes of rational numbers with unlike signs instead of subtracting the lesser magnitude from the greater and keeping the appropriate sign.                 |
| rational-number-operations                   | `orders-numbers-by-sign-alone-ignoring-magnitude`                            | Orders rational numbers using sign alone (all negatives assumed less than all positives) without comparing magnitude within a sign group.                                |
| rational-number-operations                   | `treats-absolute-value-as-always-negating-the-number`                        | Treats absolute value as always flipping a number's sign rather than as its distance from zero.                                                                          |
| coordinate-distance                          | `uses-diagonal-distance-for-an-axis-parallel-segment`                        | Computes a diagonal (straight-line) distance between two points that share a coordinate, instead of the axis-parallel distance.                                          |
| coordinate-distance                          | `subtracts-coordinates-without-taking-absolute-value`                        | Subtracts coordinates and reports a possibly negative value as a distance instead of taking the absolute value.                                                          |
| coordinate-distance                          | `swaps-x-and-y-coordinate-roles`                                             | Uses the y-coordinate difference where the x-coordinate difference was needed, or the reverse.                                                                           |
| powers-and-whole-number-exponents            | `multiplies-base-by-exponent-instead-of-repeated-multiplication`             | Computes base times exponent (e.g., treats 4^3 as 4 x 3) instead of repeated multiplication.                                                                             |
| powers-and-whole-number-exponents            | `writes-exponent-as-the-base`                                                | Writes the exponent in the base position and the base in the exponent position.                                                                                          |
| variables-and-expressions                    | `treats-variable-as-word-label-not-quantity`                                 | Treats a variable as an abbreviation or label for an object rather than a quantity that can take a numeric value.                                                        |
| variables-and-expressions                    | `substitutes-value-into-wrong-variable-position`                             | Substitutes a given value for the wrong variable when an expression has more than one variable.                                                                          |
| variables-in-context                         | `assumes-a-variable-can-only-mean-one-fixed-quantity`                        | Assumes a variable must represent one specific fixed number rather than a quantity that can vary.                                                                        |
| variables-in-context                         | `fails-to-name-the-quantity-represented-by-the-variable`                     | Writes an expression with a variable but cannot state, in words, what real-world quantity the variable represents.                                                       |
| equivalent-expressions                       | `distributes-factor-to-only-the-first-term`                                  | Multiplies a factor into only the first term of a sum or difference instead of every term.                                                                               |
| equivalent-expressions                       | `changes-operation-without-justification`                                    | Swaps an expression's operation (e.g., addition to multiplication) without a property that justifies the change.                                                         |
| equation-and-inequality-meaning              | `assumes-every-equation-requires-performing-an-operation`                    | Assumes checking whether a value satisfies an equation always requires solving/manipulating it, rather than substituting and evaluating.                                 |
| equation-and-inequality-meaning              | `treats-inequality-solution-as-a-single-value`                               | Reports one number as "the" solution to an inequality instead of describing the full solution set.                                                                       |
| one-variable-equations                       | `performs-an-operation-on-only-one-side-of-the-equation`                     | Applies an inverse operation to only one side of the equation instead of both sides.                                                                                     |
| one-variable-equations                       | `skips-substitution-check-of-solution`                                       | Reports a solution without substituting it back into the original equation to verify it.                                                                                 |
| real-world-inequalities                      | `flips-inequality-direction-without-justification`                           | Reverses an inequality's direction without a valid reason (e.g., without multiplying/dividing by a negative number).                                                     |
| real-world-inequalities                      | `graphs-endpoint-only-instead-of-solution-ray`                               | Marks only the boundary value on a number line instead of shading the full ray/segment that satisfies the inequality.                                                    |
| two-variable-relationships                   | `swaps-dependent-and-independent-variable-roles`                             | Labels the independent variable as dependent, or the reverse, in a table, graph, or equation.                                                                            |
| two-variable-relationships                   | `treats-table-rows-as-unrelated-number-pairs`                                | Reads table rows as isolated number pairs rather than instances of one consistent dependent/independent relationship.                                                    |
| polygon-area                                 | `reports-perimeter-value-as-the-area`                                        | Computes and reports the perimeter (sum of side lengths) when area was requested.                                                                                        |
| polygon-area                                 | `counts-an-overlapping-region-twice-when-decomposing`                        | Decomposes a polygon into overlapping pieces and adds both areas, double-counting the overlap.                                                                           |
| fractional-prism-volume                      | `labels-volume-answer-with-square-units`                                     | Reports a correct numeric volume but labels it with square (area) units instead of cubic units.                                                                          |
| fractional-prism-volume                      | `adds-edge-lengths-instead-of-multiplying`                                   | Adds the three edge lengths instead of multiplying them to find volume.                                                                                                  |
| coordinate-polygons                          | `uses-diagonal-point-distance-for-an-axis-parallel-side`                     | Computes a diagonal point-to-point distance for a side that is actually horizontal or vertical.                                                                          |
| coordinate-polygons                          | `swaps-horizontal-and-vertical-side-length`                                  | Reports a vertical side's length as the horizontal side's length, or the reverse.                                                                                        |
| nets-and-surface-area                        | `omits-a-congruent-face-pair-from-the-net`                                   | Leaves one face (or one of a congruent pair of faces) out of the surface-area total.                                                                                     |
| nets-and-surface-area                        | `labels-surface-area-answer-with-cubic-units`                                | Reports a correct numeric surface area but labels it with cubic (volume) units instead of square units.                                                                  |
| statistical-questions                        | `expects-a-statistical-question-to-have-one-fixed-answer`                    | Rejects a valid statistical question because it does not have one single, fixed numeric answer.                                                                          |
| statistical-questions                        | `treats-a-data-value-as-the-statistical-question`                            | States a single data value (e.g., "14 years old") as if it were the statistical question itself.                                                                         |
| distribution-description                     | `reports-only-the-maximum-value-as-the-distribution-summary`                 | Summarizes a data set by naming only its maximum value instead of center, spread, and shape.                                                                             |
| distribution-description                     | `omits-real-world-context-in-distribution-summary`                           | Describes a distribution using numbers only, without naming what was measured or the real-world context.                                                                 |
| center-and-variability                       | `reports-median-value-when-asked-for-the-mean`                               | Computes and reports the median when the mean was requested, or the reverse.                                                                                             |
| center-and-variability                       | `reports-a-center-or-spread-value-without-context-or-number-of-observations` | States a center or spread number without the units, real-world context, or number of observations needed to interpret it.                                                |

## Notes for future revisions

- Tighten any new misconception code to name a specific, checkable learner
  behavior (what they wrote, said, or computed), not a general topic area.
- Add every new code to this table before or when it is introduced in
  `skill-records-v2.json`. `validate.ts` now enforces strict 1:1 glossary
  completeness, rejects duplicate misconception codes within a skill record,
  rejects duplicate glossary rows, and rejects empty or placeholder
  descriptions. The remaining limitation is semantic: validation cannot
  determine whether a description is mathematically or pedagogically correct,
  only that it is present and non-placeholder.
